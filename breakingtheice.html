Grammar Conditionals Review

📌 Types of Conditionals

  • Type 0 (Natural Law/Fact): If + Present Simple, + Present Simple.
    "If I travel constantly, I get tired."
  • Type 1 (Present Real/Future): If + Present Simple, + Will/Won't.
    "If the flight is delayed, we will miss the meeting."
  • Type 2 (Present Unreal/Imaginary): If + Simple Past (or were), + Would/Could.
    "If I spoke Swedish, the trip would be easier."
